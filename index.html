🚀 Project Architecture & Future IoT Upgrades

📶
ESP32 / ESP8266 Migration
Replace Arduino Uno with an ESP32 SoC for onboard 2.4GHz Wi-Fi, BLE, and direct MQTT broker connection without host PC bridge.
📱
Mobile App & Blynk Cloud
Integrate Blynk IoT or Flutter mobile app for worldwide remote switching, push notifications, and customizable running light presets.
⏰
Cloud Scheduling & NTP
Implement NTP (Network Time Protocol) to trigger light chasing routines at scheduled times (e.g., store displays, festival lighting).
🎙️
Sensor & Voice Triggers
Add microphone sound sensors for music-reactive running lights, LDRs for twilight activation, and Alexa/Google Home voice control.
⚠️
College Project Disclosure: The base Arduino Uno R3 ATmega328P microcontroller has no native Wi-Fi or BLE hardware. In this project architecture, IoT connectivity is achieved via the modern Web Serial API acting as a bidirectional hardware-to-cloud bridge, accompanied by a Simulated MQTT Link. Full untethered IoT is the direct upgrade path via ESP8266/ESP32.
